# 答辩预案：主结论级质疑的应答（文献锚定版，2026-09-08）

配合策划案 V3 第九章与 README 文献依据表使用。原则：**每条主张
按「领域先例 → 我们的实例 → 边界声明」三段式应答，不降级、不
隐瞒**。先例证明方法学成立，我们的工作是把它首验于 Cas12a2。

## Q1「游离态结构指标凭什么排序？你们的复算不是阴性吗？」

- **先例**：guide 游离态二级结构特征预测活性是反复验证的方法学：
  CRISPRscan（Moreno-Mateos 2015, Nat Methods，被引>1600）、
  WU-CRISPR（Wong 2015）、CRISPRpred（Liu 2020，加入结构特征后
  预测更好）；张锋团队专利（US8889356）用 MFE+Boltzmann 配分比
  较 guide 结构——与我们同类方法。Creutzburg 2020 论文自报即为
  正相关（pre-crRNA 口径 n≈25 显著）。
- **我们的实例**：复算划定了该规律的口径边界（pre-crRNA 口径、
  同体系内），据此把打分锁定为「同 spacer 下 DR 变体的结构相对
  排序」——这是对该文献规律的保守实现，不是越界使用。
- **边界声明**：排序主张的最终确认由结合态 MD（预登记 M1/M2
  判据，进行中）与湿实验矩阵完成；Cas12a2 骨架变体-活性数据全
  领域为零，我们的矩阵将是第一批标定数据。

## Q2「骨架分型是不是过度解读小样本？」

- **先例（假说前提有综述级背书）**：Annu Rev Chem Biomol Eng
  2023 明确「spacer 与 guide 其余部分之间的二级结构相互作用是
  gRNA 活性的关键决定因素」——A–B 耦合是文献承认的分子前提。
  工程先例：MIT 的 Cas12a scaffold variants 工具箱（按上下文选
  骨架优化折叠）；EP4403638（DR 茎环保守突变的活性实验）。
- **我们的实例**：同源跨上下文交互检验 E1 通过（DeWeirdt 两大
  文库方向间 ρ=0.257，CI [0.247, 0.267]，先登记后评估）；本体
  系 86 spacer 计算证据为弱阳性（如实评级），四项事后稳健性补救
  全部完成并维持评级。
- **边界声明**：分型强度的实验级判定已预登记（骨架×靶标交互项
  ANOVA，`--anova` 就绪待数据）；若阴性，智能体按预登记退化
  为通用型单骨架推荐——结论依然完整可交付。

## Q3「Chai-1 界面高分是自模板复述，界面证据站不住吧？」

- **先例**：「共折叠初筛 + 第二方法复核」是领域标准工作流
  （arXiv:2511.14669：AF3 ipTM 筛选 + Rosetta 复核）；Chai-1
  在 PoseBusters 上 77% 与 AF3 报告的 76% 持平。ipTM 阈值惯例
  （>0.6/>0.8）针对的是绝对界面断言。
- **我们的实例**：我们只用**差量排序**（变体−WT），不做绝对界
  面断言——差量用途不以全称界面可预测性为前提；自模板高分的
  复述性质已在 README 与 JSON 中如实声明，并列入 template-free
  /scrambled 对照计划量化信息含量；Protenix 跨工具回填后提供一
  致性检验。
- **边界声明**：界面层是结构描述特征与模板合规检查，分型主张不
  依赖它。

## Q4「四个假结模型都复现不了 Sp8，是不是模型错了？」

- **先例**：Creutzburg 2020 的茎定义本身含手工假结 P1 配对——
  假结活性态是文献承认的构造；伪结外折叠空间（ViennaRNA 等）按
  构造无法表示它，这不是我们模型的错误，是表示层边界。
- **我们的实例**：我们把盲区转成了资产——v1.6 DR-spacer 交叉
  配对硬过滤（Creutzburg 设计守则的保守实现），且本体系成熟
  crRNA 无假结由 8D4A 结构 + Knotty + NUPACK 三方互证
  （W_pk 0.9–1.0%）：**盲区存在，但本体系不在盲区内**。
- **边界声明**：「模型知道自己在哪里失效」是智能体的显式功能
  （超出模型域候选打警示标签），不是缺陷掩饰。

## Q5「外部验证（Tian/DeWeirdt）相关性接近零，选型器还有用吗？」

- 这是**位置/终点边界**而非失败：Tian 集全部是 DR 5' 端 RRS 位
  点突变，我们已按位置规则把该区从候选库排除（选型器不适用区
  被显式测绘）；DeWeirdt 集动态范围由茎/环随机化主导，弱正信号
  方向正确（ρ=+0.016 ~ +0.202 口径并列报告）。
- 层级模型（部分池化、数据集随机截距）是这类多终点整合的标准
  统计解法，已列入整改路线 C。
- 选型器定位始终是「文献先验排序」（README 已声明排序权威=管
  线打分）；等自家矩阵数据回流后它会被实测数据重训——这正是
  闭环设计的目的。
