# GuideForge 判据预登记（PASS/FAIL criteria registry）

- **登记日期**: 2026-09-04
- **性质**: 本文件是**补登记（retroactive consolidation）**，不是这些判据的首次成文——
  各判据此前散落在评估脚本内（多数与评估代码同文件、同提交），首次成文时间以 git
  历史为准。本文件把它们集中一处，并如实标注每条判据的来源性质。
- **生效规则（自登记之日起）**: 任何 PASS/FAIL 判据的**新增、改值、改口径**，必须先
  修改本文件并注明日期，再改评估代码、再跑评估运行。判据与评估运行同提交落地即
  视为违反本规则。失败的预登记判据必须出现在 README 头条结论中，不得只留在 JSON 内。
- **评审背景**: round-2 评审共同关切 #2（alfa #4/#6, bravo #1, charlie #7）指出
  仓库自称"预登记/先定后跑"的多个阈值实际由被评估数据导出，或普遍触发后被事后
  重述。本文件为该关切的整改物。

## 来源性质的诚实标注定义

- **真预登记**: 判据在对应评估运行之前已成文（有独立于评估代码的、带日期的载体），
  且数值不来自被评估数据。
- **项目设定常数（同文件定义）**: 判据是人为选定的常数，不来自被评估数据，但写在
  评估脚本内、与评估同提交，无独立带日期载体。自称"先定后跑"名不副实；本文件的
  登记使其此后具备预登记效力，但历史运行不适用"预登记"表述。
- **事后从数据导出**: 判据数值是被评估数据（或其子集）的函数。其中若使用了
  留出/测试部分的数据，另标注"**泄漏**"。

## B. 系综采样检验 R1–R4 规则

- **判据原文**（`scripts/crrna_ensemble_check.py:13-17, 37-40, 173-182`）:
  > R1 |ΔΔG_mfe − ΔΔG_ens| > 1.0  (MFE 点估计偏移过大)
  > R2 std(ΔΔG_sample) > |ΔΔG_ens| (采样噪声超过效应量)
  > R3 max−min(ΔΔG_sample) > 4.0  (跨构象跳变过大)
  > R4 茎完整构象占比在 20%~80% 之间 (构象二态)
- **当前实现位置**: `scripts/crrna_ensemble_check.py:37-40`（常量表 RULES）、
  `:173-182`（触发逻辑）；输出 `data/ensemble_check.{pdbdr.v2,zengdr.v6}.json`。
- **来源性质**: **项目设定常数（同文件定义）**；脚本自述"判不稳阈值为项目设定，
  非文献出处"。此前无独立预登记载体。
- **统计构造缺陷（如实标注，alfa round-2 #4）**: R2/R3 作用的统计量
  `ddG_samp = e_v − e_w` 把**两组相互独立的 Boltzmann 抽样按采样序号配对**求差，
  其 std 按构造 ≈ √(sd_v² + sd_w²)（本库实测 ≈ √2×0.9~1.0 ≈ 1.3 kcal/mol，与观测
  ddG_sample_std 1.3~1.4 一致）——R2/R3 是在普通系综涨落尺度上武装的噪声探测器，
  对 |ΔΔG_ens| ≲ 1.3 kcal 的候选按构造必然触发，**无法检出它想检的病理**。修复方向
  （未实施）: 改用匹配热力学量（如窗口均值能量差的 bootstrap），或用 WT 分裂半
  （WT-vs-WT split-half）标定零触发率后再定阈。
- **判据重设计（2026-09-04 round-3 补充，登记先于评估运行）**: 旧 R2/R3 退役（统计构造
  病态，见上；旧数值保留于输出 JSON `deprecated_ill_posed_R2R3` 仅供溯源，不再参与判定），
  替换为良态统计量——
  > R2′ 序翻转检验：仅对声称有实效的候选（|ΔΔG_ens| ≥ 1.0 kcal/mol，项目设定常数）判定；
  >   P_contra = P（逐构象能量序与窗口均值序相反），由两枚举窗口 Boltzmann 权重卷积精确计算
  >   （无采样序号配对、无抽样噪声）; P_contra > 0.2（项目设定常数）→ 触发。
  >   |ΔΔG_ens| < 1.0 的近中性候选不判定（其"无实效"即主张本身），P_contra 随行披露。
  > R3′ 景观粗糙度：spread_ratio = sd_ens(E_var)/sd_ens(E_WT)（枚举窗口内 Boltzmann 加权
  >   精确值，非 100 采样估计）; ratio > 2.0（项目设定常数）→ 触发。零分布标定：WT 枚举
  >   集随机分裂半 200 次，ratio 零分布 p95/max/超阈经验率随输出 `r3_null_calibration`
  >   报告（阈值假阳性率须 ≤1% 方可采信）。
  R1/R4 不变；结论强度由 R1+R2′+R3′+R4 共同决定。
- **最新结果**（2026-09-04 重设计判据评估，登记先于运行）: **重设计判据下两口径
  `conclusion_strength` 均为 `passed_all_rules`**——R1 触发 0/24（|shift|≤0.03）；
  R2′ 序翻转：6 条实效候选（|ΔΔG_ens|≥1.0，pdbdr 4 + zengdr 2）P_contra 最大
  0.13（阈 0.2），触发 0/24；近中性候选 18 条按登记不判定（P_contra 0.22~0.78
  逐候选披露，属普通热涨落重叠）；R3′ 景观粗糙度：展宽比最大 1.14（阈 2.0），
  触发 0/24，WT 分裂半零分布超阈经验率 pdbdr 2/200=1.0%、zengdr 1/200=0.5%
  （≤1% 采信线内）；R4 触发 0/24（茎完整率改枚举窗口精确值，范围 0.83~0.87，
  消除原 100 采样估计在 0.8 判界附近的噪声）。**"打分输入端在系综采样下稳定"
  主张在重设计判据下成立。** 历史记录（如实保留）：旧 R2/R3（病态构造）曾触发
  19/24、24/24（zengdr 10/12、pdbdr 9/12），当时对外只报 R1 腿的"主张成立"，
  属不实头条；round-3 先降级为 `downgraded_R1_leg_only`，本次判据重设计并登记后
  方升级为通过——旧数值留档 JSON `deprecated_ill_posed_R2R3`（构造值
  √(sd_v²+sd_w²) 与观测 ddG_sample_std 逐候选最大偏差 0.08/0.09 kcal，复现一致）。
